# 練習用プロジェクト（Drag & Drop Practice）

初めてGitHubにファイルをアップロードする練習用のリポジトリです。
このリポジトリでは、ブラウザのドラッグ＆ドロップ機能を使ったファイルのアップロード手順を確認しています。

## 📌 このリポジトリの目的
- GitHubの基本的な使い方（リポジトリ作成・ファイルのアップロード）の習得
- Markdown（README.md）の書き方の確認

## 🚀 使い方 / 取扱説明書
1. GitHubのアップロード画面を開く
2. この `README.md` やその他のファイルをドラッグ＆ドロップする
3. 「Commit changes」ボタンを押して保存する

## 🛠 使用技術
- Markdown
- GitHub (Web Interface)
